HOW IT WORKS

A clear path from image to useful context.

The existing TensorFlow model processes supported uploads. Results are model predictions, not confirmed diagnoses.

  1. 01

    Choose a clear crop image

    Use a well-lit image of a supported crop leaf in an accepted image format.

  2. 02

    Submit it to the scanner

    The server validates the upload and checks that the trained model is available.

  3. 03

    Review the model output

    See the predicted class and confidence score with the available disease guidance.

  4. 04

    Keep records and use judgement

    Save the result to your private history and consult a local agricultural expert before treatment.
