FREQUENTLY ASKED QUESTIONS

Good to know before you begin.

How does crop scanning work?

The authenticated scanner validates an uploaded image and sends it to the bundled TensorFlow classifier. The result is a model prediction and confidence score.

Which crops are supported?

{% if supported_crops %}The model's crop groups are {{ supported_crops|join(", ") }}. Images outside the training classes may not be identified reliably.{% else %}The crop classifier is not configured in this deployment, so image predictions are unavailable.{% endif %}

Does the confidence score guarantee accuracy?

No. It is the model's score for its selected class, not a probability that the result is correct or a confirmed diagnosis.

What image should I upload?

Use a clear, well-lit crop-leaf image. The server accepts JPG, JPEG, PNG and WebP uploads up to 10 MB.

Where are my scans and images stored?

Saved detections and uploaded images are associated with your account and are not visible to other farmer accounts.

Can I use CropFarmAI on a phone?

Yes. The Flask workspace is responsive for mobile and desktop browsers. A stable network is needed for hosted weather information.

Which languages are fully translated?

English, Hindi, Assamese and Bengali have translated welcome and core account, navigation and dashboard text. Other languages use English fallback where translations are not yet available.

How does password recovery work?

Password recovery uses a one-time email link when SMTP is configured. Email/SMS OTP delivery is not configured in this installation.

Is an AI chat assistant available?

No chat assistant is connected in this Flask installation. The public site does not advertise one as an available feature.
